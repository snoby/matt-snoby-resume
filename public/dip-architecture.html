Modes — vector, keyword, or hybrid via request body or SEARCH_MODE

/ask evidence threshold defaults to ASK_MIN_RERANK_SCORE=-5.0
Works with any OpenAI-compatible LLM endpoint
Request telemetry is stored in SQLite and exposed through /metrics
Runtime Components
FastAPI service runs from /opt/dip and serves /health, /search, /ask, and /metrics on port 8080
Qdrant container persists vectors under /var/lib/dip/qdrant-storage
SQLite registry lives under /var/lib/dip/state/registry.sqlite3 with WAL enabled
Markdown cache is written under /var/lib/dip/markdown by content SHA
systemd timer launches incremental ingestion every 30 minutes
OCR is not enabled; scanned PDFs and images remain a future phase
API Endpoints — How to Use
GET /health System status 
# Check system status
curl http://ragdb:8080/health
Response
{
  "status": "ok",
  "collection": "business_docs",
  "rerank_enabled": true,
  "search_mode": "hybrid",
  "llm_configured": true
}
POST /search Semantic search 
curl http://ragdb:8080/search \
  -H 'content-type: application/json' \
  -d '{
    "query": "commissioning report",
    "top_k": 5,
    "use_rerank": true,
    "mode": "hybrid"
  }'
Response
{
  "results": [{
    "chunk_id": "abc123:000002",
    "file_name": "CommPlan.pdf",
    "section_title": "Requirements",
    "score": 4.21,
    "text": "..."
  }],
  "reranked": true,
  "mode": "hybrid"
}
POST /ask Grounded Q&A 
curl http://ragdb:8080/ask \
  -H 'content-type: application/json' \
  -d '{
    "question": "What does the
      commissioning plan require?",
    "top_k": 8,
    "use_rerank": true
  }'
Response
{
  "answer": "The plan requires... [1]",
  "citations": [{
    "citation_id": 1,
    "source_path": "/data/...",
    "section_title": "Requirements",
    "rerank_score": 4.21
  }],
  "confidence": "high",
  "llm_used": true
}
